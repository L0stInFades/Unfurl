# Unfurl v0.1.1.1

This release increases only the fourth version component, from `0.1.1.0` to `0.1.1.1`. Compression reuses one streaming buffer across directory traversal, avoiding a large stack allocation at every level. Incomplete source reads now fail with staging cleanup, hard links are explicitly rejected, and split-volume cancellation is checked inside each copy loop. The UI bounds pending progress callbacks, releases cleared preview storage, and avoids redundant responsive-layout setters. Native WinUI motion and the existing interface are retained.

Download and open `UnfurlSetup.exe` normally. The standalone WinUI 3 installer embeds the public certificate and update feed, prepares missing Microsoft runtime components, and requests administrator confirmation only when certificate trust is needed. It opens Windows App Installer for the final installation confirmation and automatic-update enrollment. No adjacent files are required; the signed installer is under 1 MiB. A native preparation dialog handles machines where WinUI is not available yet.

The build uses precompiled WinUI headers and dependency-aware C++/WinRT generation. Performance verification follows Microsoft's WinUI guidance with WPR CPU/XAML/GPU traces and WPA XAML Frame Analysis; methodology, measurements, and coverage limits are documented in `docs/performance.md` and `docs/verification.md`.

In-page corners use WinUI's shared `ControlCornerRadius` resource, correcting the custom 6-DIP drop area and the setup card. Window and flyout rounding remains native. Setup uses WinUI title typography, theme resources, and accessible status announcements. PowerShell entry points require version 7, pass PSScriptAnalyzer, and installation scripts support `-WhatIf`; the native setup itself does not run PowerShell.

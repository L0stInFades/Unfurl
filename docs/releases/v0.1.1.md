Unfurl 0.1.1 keeps the same Windows 11 x64 archive workspace and signed App Installer update channel as 0.1.0. This release restores native checkbox contrast on the extract page.

- Archive row checkboxes now inherit WinUI's `DefaultListViewItemStyle`, so the checked fill, theme states, and focus visuals match the header checkbox in Light and Dark appearance (issue #2).
- The clang-tidy compile database no longer depends on generated C++ module maps.

MSIX identity, publisher, architecture, and the signing certificate are unchanged. The four-part package version is `0.1.1.0`. Users who installed through `Unfurl.appinstaller` receive this release from the existing latest feed.

### Installation

Download **Unfurl.cer** and **Unfurl.appinstaller**. This release is self-signed, so first verify and trust the public certificate using the [installation instructions](https://github.com/L0stInFades/Unfurl/blob/v0.1.1/docs/updates.md#install). Its thumbprint is `7D6647D7B3568C1517146B098A55488ADF5A4BA1`. Then open **Unfurl.appinstaller** to install the app and its Microsoft-signed runtime dependencies and enroll in automatic updates.

The standalone MSIX and portable **Unfurl-Release.zip** are also provided; neither enrolls in automatic updates when installed on its own. The portable ZIP includes the Windows App Runtime installer payload and optional Explorer integration scripts. SHA-256 hashes for all assets are in **SHA256SUMS.txt**.

Windows 11 x64 and Windows App Installer are required for the updating installation. The publisher certificate is self-signed and is not automatically trusted by Windows. No private signing key is included in this release.

Unfurl 0.1.0 is a native Windows 11 x64 archive workspace with a Simplified Chinese WinUI 3 interface.

- Preview and extract archives; create ZIP, 7Z, TAR.GZ, TAR.BZ2, TAR.XZ, and TAR.ZST.
- ZIP passwords and split volumes, cancellation, Unicode filenames, and no-overwrite output handling.
- Signed MSIX installation with automatic updates managed by Windows App Installer. The feed checks at launch and through Windows' eight-hour background schedule.

### Installation

Download **Unfurl.cer** and **Unfurl.appinstaller**. This release is self-signed, so first verify and trust the public certificate using the [installation instructions](https://github.com/L0stInFades/Unfurl/blob/v0.1.0/docs/updates.md#install). Its thumbprint is `7D6647D7B3568C1517146B098A55488ADF5A4BA1`. Then open **Unfurl.appinstaller** to install the app and its Microsoft-signed runtime dependencies and enroll in automatic updates.

The standalone MSIX and portable **Unfurl-Release.zip** are also provided; neither enrolls in automatic updates when installed on its own. The portable ZIP includes the Windows App Runtime installer payload and optional Explorer integration scripts. SHA-256 hashes for all assets are in **SHA256SUMS.txt**.

Windows 11 x64 and Windows App Installer are required for the updating installation. The publisher certificate is self-signed and is not automatically trusted by Windows. No private signing key is included in this release.
